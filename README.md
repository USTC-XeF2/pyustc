中国科学技术大学网络服务 Python 库。

## 功能特性

- **统一身份认证服务**：简化登录与会话管理。
- **教务系统**：课表、成绩及选课工具。
- **第二课堂平台**：管理第二课堂活动。
- **体育场馆​​预订**：浏览场馆、查询空闲状态及管理个人订单。

## 安装与使用

```bash
pip install pyustc
```

有关示例和详细文档，请参阅 [示例](https://github.com/USTC-XeF2/pyustc/tree/main/examples)。
